What is Product Factory

Nine agents.
One cluster.
Zero bottlenecks.

Product Factory is an AI agent cluster powered by Claude and AWS Bedrock that autonomously analyzes software, validates database operations, and accelerates engineering workflows — without a human in the loop.

"Each agent carries a codename and a precise directive."

They integrate directly with JIRA, poll for labeled tickets, execute analysis against live codebases, and post structured results back — in minutes, not hours.

The Workflow

From ticket to result.
Fully autonomous.

A single labeled JIRA ticket triggers the full pipeline — from routing and workspace setup, through live analysis, to a structured result posted back to the ticket. No human intervention required at any step.

01
Ticket Arrives

JIRA ticket is labeled. Orchestrator polls, extracts context, determines the target agent and relevant repository workspace.

→
02
Agent Dispatched

Task enters MySQL queue. Specialized worker picks it up, initializes the agent with repo context and the appropriate permission scope.

→
03
Autonomous Analysis

Agent runs via Claude SDK on Bedrock, traversing the codebase with Read / Glob / Grep. Real-time status streams via WebSocket.

→
04
Result Posted

Structured output uploaded to S3. Orchestrator formats and posts the analysis directly back to the originating JIRA ticket.

Access Control

Five levels.
Zero overreach.

Every agent operates within a strict permission boundary. Capabilities are granted by role, not default — ensuring controlled, auditable, and reversible execution at every level.
